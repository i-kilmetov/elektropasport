# Электропаспорт

Telegram Mini App для оцифровки электрических щитков квартир и частных домов.

## Стек

- Next.js (App Router) + TypeScript
- Tailwind CSS
- shadcn/ui
- Framer Motion
- `@tma.js/sdk` (Telegram Mini App)

## Запуск

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

## Текущий поток

1. Приветствие
2. Список объектов
3. Инструкция → камера телефона → превью «Всё ок?» → **Отправить**
4. Демо-анализ (без ИИ)
5. Интерактивная схема (демо-данные)

AI-распознавание пока не подключено: фото реальное, результат схемы демонстрационный.
