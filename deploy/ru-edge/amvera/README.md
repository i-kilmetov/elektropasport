# Устарело для Amvera в Москве

Прокси nginx → Vercel из Yandex Cloud / Amvera РФ получает **upstream timed out**
до IP CDN Vercel. Не используйте эти файлы для `tokom-edge`.

Актуальный прод: **`amvera/Dockerfile`** + **`amvera.yaml`** в корне репозитория  
(см. [`amvera/README.md`](../../amvera/README.md)).

Эти файлы можно взять только для VPS **вне** РФ, откуда до Vercel есть сеть.
