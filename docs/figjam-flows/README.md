# Процессы Током — диаграммы для FigJam

Набор **диаграмм активности** (user flows) сервиса Током, разбитых по доменам.

## Как открыть в FigJam

### Способ A — SVG (рекомендуется)
1. Откройте [FigJam](https://www.figma.com/figjam/) → New board.
2. Перетащите файлы `*.svg` из этой папки на доску (или *File → Place image…*).
3. Разложите домены как отдельные фреймы / секции.

### Способ B — Mermaid-текст (редактируемые фигуры)
1. Установите плагин FigJam **Mermaid** (Community → Plugins → «Mermaid»).
2. Откройте нужный `.mmd` в редакторе, скопируйте содержимое.
3. В FigJam: Plugins → Mermaid → Paste → Generate.
4. Получите нативные ноды FigJam, которые можно двигать и стилизовать.

### Способ C — весь архив
Скачайте / откройте `docs/tokom-user-flows-figjam.zip` и импортируйте SVG пачкой на доску FigJam.

## Легенда на диаграммах

- **Чёрный скруглённый блок** — старт / переход в другой домен / финиш  
- **Ромб** — решение пользователя или системы  
- **Серый блок** — результат в данных (сессия, заявка, оплата)  
- **Жёлтый акцент** — шаги UI Током  

## Актёры

| Актёр | Где живёт |
|-------|-----------|
| Гость | waitlist, auth, /research, /job |
| Пользователь | objects, scheme, school, Plus |
| Мастер | MasterDashboard + user mode |
| Админ | admin через профиль |

Обновлено под код `main` на момент генерации (лимиты Плюс: 3 щитка / 10 техники / −10% / клеммы).
