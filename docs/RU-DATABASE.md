# База данных в России (152-ФЗ)

Персональные данные пользователей из РФ должны храниться на серверах в России. Для этого используйте переменную **`RU_DATABASE_URL`** — она имеет приоритет над `DATABASE_URL` (Neon).

## Рекомендуемый провайдер: Amvera Cloud

Постоянно бесплатного PostgreSQL в РФ нет. **Amvera** — российский хостинг с управляемым PostgreSQL:

1. Регистрация: [amvera.ru](https://amvera.ru) (при регистрации начисляется пробный баланс ~111 ₽).
2. Маркетплейс → **PostgreSQL** → создать кластер (тариф «Начальный» от ~290 ₽/мес после исчерпания бонуса).
3. Скопировать строку подключения вида:
   `postgresql://user:password@host:5432/dbname?sslmode=require`
4. В **Vercel → Settings → Environment Variables** добавить:
   - `RU_DATABASE_URL` = строка подключения Amvera
   - `OPERATOR_INN` = ваш ИНН самозанятого (для документов)
   - `OPERATOR_EMAIL` = e-mail для обращений по ПДн (например `support@tokom.ru`)
5. Пер redeploy проекта. При первом запросе к API выполнится миграция схемы (`ensureSchema`).

## Миграция с Neon

1. Создайте кластер в Amvera.
2. Экспортируйте данные из Neon (`pg_dump`) и импортируйте в Amvera (`psql`), либо начните с чистой БД — пользователи войдут заново через Telegram.
3. Установите `RU_DATABASE_URL` в Vercel.
4. После проверки можно удалить `DATABASE_URL` или оставить как резерв.

## Альтернативы

- **Yandex Managed PostgreSQL** — надёжно, но платно (есть грант для новых аккаунтов).
- **Selectel, Timeweb Cloud** — от ~200–400 ₽/мес.

## Проверка

После деплоя откройте сайт, войдите через Telegram с галочкой согласия. Если API отвечает без «Внутренняя ошибка сервера» — БД подключена. В Amvera в логах/метриках должны появиться подключения.

## Юридические страницы

- `/legal/privacy` — политика конфиденциальности  
- `/legal/terms` — пользовательское соглашение  
- `/legal/offer` — публичная оферта  
- `/legal/consent` — текст согласия на обработку ПДн  

Оператор: Кильметов Ильдар Ринатович, самозанятый. ИНН подставляется из `OPERATOR_INN`.
