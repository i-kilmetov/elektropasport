# Amvera: прод Током + зеркало Vercel

## Деньги

**Не бесплатно.** Приложение `tokom-edge` тарифицируется отдельно от Postgres:

| Тариф | Ориентир |
|-------|----------|
| Пробный | ~170 ₽/мес (мало RAM — для Next обычно мало) |
| **Начальный** | ~**290 ₽/мес** (типичный минимум для сайта) |
| Начальный Плюс | ~490 ₽/мес |

Поминутная оплата только пока контейнер запущен. Postgres (`tokom`) — отдельный счёт.

## Как устроено сейчас

- DNS `tokom.ru` → Amvera.
- В Code проекта `tokom-edge`: `Dockerfile` **клонирует** публичный GitHub `i-kilmetov/elektropasport` (`main`) и собирает Next.js.
- Push в GitHub → Vercel обновляется сам; Amvera подтянет код на **Пересобрать** (или по вашему CI).
- Переменные заданы в Amvera → Переменные (тип RUN; `NEXT_PUBLIC_*` ещё и BUILD).

## Пересборка после правок кода

Amvera → `tokom-edge` → **Пересобрать проект**.  
Сборка тянет свежий `main` с GitHub (~5–15 мин).

## Откат на Vercel

1. DNS снова на Vercel.  
2. Amvera → реплики 0 / заморозить.  
3. Код на Vercel уже актуален с GitHub.
